# Post-deployment SEO measurements

Deployment is not authorized by this implementation task. All changes remain local. After an approved deployment, record its timestamp, commit and domain here and verify the public host before submitting the sitemap.

## Day 0: verify delivery

- Repeat the HTTP redirect/header checks against the deployed Vercel host. Verify all 31 original encoded aliases and the Semax migration, including query strings, slash variants and index.html aliases. Each must terminate directly at its canonical 200 URL.
- Inspect raw HTML and run Search Console live tests for shipping policy, N-Acetyl Semax Amidate, COA library, shop, BPC-157 and BPC-157/TB-500. Check HTTP status, canonical, rendered content and JSON-LD.
- Verify seven private shells expose matching noindex meta and X-Robots-Tag with private/no-store caching; robots.txt allows crawling these shells. Confirm no private data appears in their initial HTML. Account authorization remains responsible for private data access.
- Confirm /cart/ and unknown URLs return 404; opening the cart drawer preserves the public page's indexability.
- Confirm sitemap.xml contains exactly 136 canonical indexable URLs, including the new Semax URL and excluding the old alias, private pages and error template.
- Submit the sitemap and request indexing for the six priority pages. Record any indexing requests, schema validations and deployment observations.
